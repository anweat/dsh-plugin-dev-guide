# 安全与合规审查经验

> 维度：security ｜ 优先级：P0（场景专属）

## 高频问题

1. **加密与防篡改缺失**：卡片/接口获取环节无加密、签名校验，存在 URL 外泄、参数篡改风险。
2. **鉴权链路不闭环**：授权码换取、身份校验、绑定校验等环节存在跳步。
3. **实名/敏感信息用途不明**：新增实名信息接口调用未明确业务用途。
4. **数据暴露面未核实**：仅一句「无暴露风险」而无链路依据。

## 典型意见摘录（真实）

- 「方案建议后续 APP 附件 ID 加密能力上线后，统一按照加解密流程执行当前业务」
- 「方案建议进一步完善 RDS 加密防护手段」
- 「明确卡片获取时相应的安全防护措施与加密策略，避免 URL 外泄、参数被篡改所导致的风险」
- 「方案需明确新增实名信息接口调用的业务用途」

## 审查要点

- 对外/三方接入必须明确加密、签名、防篡改手段。
- 鉴权链路必须完整闭环，时序图体现每一步。
- 敏感数据（实名、手机号等）调用必须说明业务用途与合规依据。
- 「无暴露风险」结论必须附链路依据，不能是断言。
